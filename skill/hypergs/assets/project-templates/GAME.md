# Game Brief

## Vision

Describe the game in one sentence.

## Player

Define the primary audience, platform, session length, and accessibility needs.

## Experience Pillars

List three testable qualities the experience must preserve.

## Core Loop

Describe the shortest repeatable player loop.

## Scope Boundaries

List the must-have slice, explicit non-goals, constraints, and assumptions.

## Success Signals

Define observable product, playtest, technical, and business signals.

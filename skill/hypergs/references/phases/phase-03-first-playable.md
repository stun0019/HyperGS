# Phase 03 — First Playable

## Objective

Deliver the shortest presentation-ready implementation that demonstrates the core player action and feedback loop at the requested device and quality target.

## Lead and support

Lead: Client Engineer. Required reviewers: Game Designer, UI/UX Designer, Art Director, and Producer. Require Server Engineer review when the Genre Promise Contract claims online, shared, persistent server state, or MMO behavior.

## Required outcomes

- A reproducible launch path
- One complete input-to-outcome loop with integrated controls, gameplay resolution, animation, feedback, UI, and environment presentation
- Runtime capture at target device scale
- A playtest focused on comprehension, control, impact, readability, visual coherence, and immediate engagement
- Separate gameplay, UI/UX, art, and producer verdicts
- A Genre Promise review proving every named pillar in the running build or correcting the public label
- A market visual review showing that implemented 2D, 3D, UI, animation, and VFX choices match the sourced synthesis
- An animation review proving representative player and enemy motion states and event-synchronized combat feedback

## Exit gate

Read `prototype-quality.md`, `genre-promise.md`, `market-visual-benchmark.md`, and `art-style-system.md`. Pass only when a person can run the build, perform the intended loop, receive clear and satisfying feedback, observe every named genre pillar, and verify the implemented visual/VFX synthesis against current sourced gameplay references. Require `build.md`, `playtest.md`, runtime capture, `gameplay-review.md`, `genre-review.md`, `market-visual-review.md`, `animation-review.md`, `uiux-review.md`, `art-review.md`, and `producer-review.md`. Static cutout gameplay characters, primitive placeholder effects, missing motion states, unsynchronized hits, debug-scale actors, gameplay-obscuring HUD, contradictory visual languages, unsupported genre labels, unsourced market claims, or VFX approved from still images are blocking defects. A polished isolated arena fight does not pass an MMORPG claim without representative shared-world, persistence, role progression, and player-presence evidence.

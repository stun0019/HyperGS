# Unreal Adapter

## Detect

Confirm a `.uproject`, engine association, enabled plugins, modules, target files, configuration, maps, and required source or Blueprint assets.

## Architecture

Respect Unreal lifecycle, authority, replication, asset references, and module boundaries. Keep replicated state authoritative, avoid unnecessary ticking, and document Blueprint/C++ ownership.

## Verify

Use the associated engine and available automation tests. Compile affected targets, inspect logs, open or command-run representative maps, validate packaging prerequisites, and profile representative runtime behavior.

Large binary assets and missing engine installations can limit verification; report the exact limitation and completed checks.

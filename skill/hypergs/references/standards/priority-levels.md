# Priority Levels

Use priority to express player and release impact, not personal preference.

| Level | Meaning | Expected response |
|---|---|---|
| P0 | Safety, security, data-loss, legal, or complete-service failure | Stop affected release or operation and address immediately |
| P1 | Core loop, launch, purchase, save, or critical progression is blocked | Fix before the relevant gate passes |
| P2 | Material degradation with a usable workaround | Schedule within the current milestone when feasible |
| P3 | Minor defect, polish, or low-impact improvement | Place in the ordered backlog |

Raise priority for broad reach, high reproducibility, irreversible harm, or no recovery path. Lower it when impact is narrow, recoverable, and outside the current target.

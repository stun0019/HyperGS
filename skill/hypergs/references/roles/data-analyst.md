# Data Analyst

**Role ID:** `data_analyst`

## Mission

Turn product questions into privacy-aware measurements that improve decisions without substituting metrics for judgment.

## Own

- Metric definitions, event taxonomy, funnels, cohorts, balance telemetry, experiment design, data-quality checks, and interpretation limits

## Deliverables

Update `ANALYTICS.md`, define event names and properties, connect every event to a product question, and document expected validation and retention rules.

## Review checks

- Metrics have a decision owner and action threshold.
- Events avoid unnecessary personal data.
- Client and server sources of truth are explicit.
- Sample size and bias limits are disclosed.

## Handoff

Provide instrumentation contracts to engineers, findings to game design, and decision-ready evidence to the producer.

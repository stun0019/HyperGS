# Balance Review Workflow

## Lead and support

Lead: Game Designer. Support: Data Analyst, Producer, and engineers owning the simulation or configuration.

## Procedure

1. State the intended player experience and affected decision.
2. Inventory sources of power, cost, time, risk, reward, and variance.
3. Identify authoritative configuration and protect it with validation.
4. Use deterministic calculations, simulations, playtests, or observed telemetry as appropriate.
5. Change the fewest variables necessary and define guardrail metrics.

## Completion

Report values changed, rationale, evidence quality, expected behavior, side effects, and the next observation window. Never present synthetic data as player behavior.

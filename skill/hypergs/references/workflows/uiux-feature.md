# UI/UX Feature Workflow

## Lead and support

Lead: UI/UX Designer. Support: Client Engineer, Game Designer, and Art Director.

## Procedure

1. Define the player goal and entry, success, cancellation, loading, empty, and error states.
2. Map the shortest coherent flow and input methods.
3. Define hierarchy, feedback, text intent, accessibility, and responsive behavior.
4. Implement the smallest interactive flow in the actual runtime when authorized.
5. Verify keyboard, pointer, touch, controller, focus, scale, contrast, and recovery as applicable.

## Completion

Provide a reviewable interaction, state coverage, usability criteria, implementation evidence, and known accessibility gaps.

# Backend Feature Workflow

## Lead and support

Lead: Server Engineer. Support: Client Engineer, Data Analyst, and Producer.

## Procedure

1. Establish whether a server is necessary and define the trust boundary.
2. Specify contracts, authorization, validation, errors, timeouts, retries, idempotency, schemas, and migrations.
3. Define local-development and production-like verification paths.
4. Implement server and client integration with contract and failure tests.
5. Review secrets, personal data, logging, rate limits, observability, backup, rollback, and operating cost.

## Completion

Provide verified contracts and failure behavior. Do not deploy, migrate production data, purchase services, or use credentials without explicit authority.
